# Canvas「对象与历史」试用清单

1. 打开上方入口 → 左侧有「对象与历史」，页面显示3个对象与4笔历史；醒目标注「示例数据」，说明来自隔离示例环境、不来自真实世界。
2. 查看对象与时间线 → 没有保存名称的对象显示「未命名对象」，对象列出位置、占地大小和实际占用，已撤回对象没有占地；每笔历史显示时间、批量区域或逐格方式、影响格数，以及已提交或已撤回状态。
3. 点击「刷新」 → 示例对象、历史、时间与影响格数保持一致。
4. 关闭页面，再打开上方入口 → 示例仍可查看，3个对象、4笔历史及各笔时间保持一致。
5. 关闭「示例数据」并点击「刷新」 → 返回真实记录；当前无会话时，示例对象与历史消失，并说明没有真实记录的原因。
6. 点击「查看示例数据」 → 回到相同的示例对象与历史；页面只有查看与刷新操作，没有建造、修改或撤回按钮。

通过标准：上述可见结果均符合；示例来源与真实空原因明确，显示字段来自已保存的记录，重开后内容保持一致。

当前试用展示隔离示例环境的记录，不代表真实世界已验证。只有 owner 明确接受才记 ACCEPTED。
